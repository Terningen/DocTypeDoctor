> [!IMPORTANT]
> ## Version Compatibility
> - 17.x is compatible with Umbraco version 17.

DocTypeDoctor is an Umbraco package that provides analysis tools for document types. It helps identify similar document types, unused properties, composition chains, and property naming issues to improve content model quality and maintainability.
